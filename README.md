# Ruby Library Management System

This is a simple little library management system I built to help me learn Ruby.

## Features
- Add new books
- Register new users
- Search for books by title or author
- Lend and return books
- List borrowed books for a user
- Remove books from the library
- List all books

## Getting Started

1. **Requirements:**
   - Ruby

2. **Run the program:**
   ```sh
   ruby main.rb
   ```

3. **Follow the on-screen menu** to interact with the library system.

## File Structure
- `main.rb` — Main CLI interface
- `book.rb` — Book class
- `user.rb` — User class
- `library.rb` — Library class
